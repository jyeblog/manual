下面我用**简单、实用的中文**，一步一步教你如何使用这台 **Haier 微波炉（型号：HMV1472BHS，上置式微波炉）**。按“日常加热 / 解冻 / 常用功能”来讲，看完就能直接用。

---

### 一、先认识控制面板（很重要）

你这台微波炉主要按钮有这些：

* **数字键（0–9）**：输入时间、重量
* **START / +30 SEC（开始 / 加30秒）** ✅ 最常用
* **STOP（停止 / 取消）**
* **POWER LEVEL（功率）**
* **DEFROST（解冻）**
* **SENSOR COOK（感应烹饪）**
* **SENSOR REHEAT（感应加热）**
* **POPCORN（爆米花）**
* **KITCHEN TIMER（厨房计时器）**
* **CLOCK（时钟）**
* **TURNTABLE ON/OFF（转盘开关）**
* **LIGHT（炉灯） / VENT（排风）**（和炉灶有关）

---

### 二、最基本的用法（加热食物）

#### ✅ 方法一：最简单（推荐）

👉 **直接按 START / +30 SEC**

* 每按一次 = **高火（100%）加热 30 秒**
* 食物不够热 $\rightarrow$ 再按一次

✅ 非常适合：
* 剩饭剩菜
* 牛奶、汤
* 快速加热

---

#### ✅ 方法二：手动设置时间

1. 把食物放进微波炉（必须放在玻璃转盘上）
2. 输入时间
   * 例如 **2 分钟** $\rightarrow$ 按 `2 0 0`
3. 按 **START**

👉 默认就是 **100% 高火**

---

### 三、调整功率（很有用）

有些食物不适合一直高火（比如解冻、黄油、汤）。

#### ✅ 设置功率步骤：

1. 输入时间
2. 按 **POWER LEVEL（功率）**
3. 输入功率（1–10）
4. 按 **START**

#### 🔢 常用功率参考：

| 功率 | 适合用途 |
| --- | --- |
| 10 = 100% | 快速加热 |
| 7 = 70% | 普通熟食 |
| 5 = 50% | 汤、咖啡 |
| 3 = 30% | 巧克力、软化 |
| 1 = 10% | 保温 |

📌 **例子：**
> 加热汤 3 分钟，用 50%  
> $\rightarrow$ `3 0 0` $\rightarrow$ POWER LEVEL $\rightarrow$ `5` $\rightarrow$ START

---

### 四、解冻食物（DEFROST）

#### ✅ 按重量解冻（推荐）

1. 按 **DEFROST**（一次）
2. 按 **START**
3. 输入重量（以 **磅 lb** 为单位）
   * 例如 1.2 lb $\rightarrow$ 按 `1 2`
4. 按 **START**

🛌 解冻到一半会提示你翻面，这是正常的。

---

#### ✅ 按时间解冻

1. 按 **DEFROST**（两次）
2. 按 **START**
3. 输入时间
4. 按 **START**

---

### 五、智能加热（不用设时间）

#### 🔥 SENSOR REHEAT（感应加热）

适合剩菜，不用猜时间。

1. 按 **SENSOR REHEAT**
2. 反复按，选择类型：
   * 饮料
   * 一盘饭
   * 披萨
   * 汤
   * 砂锅/意面
3. 按 **START**

⚠️ 加热时 **不要开门**，否则会取消程序。

---

#### 🍳 SENSOR COOK（感应烹饪）

适合做简单食物：
* 土豆
* 蔬菜
* 米饭
* 冷冻食品
* 冷冻披萨
* 培根

👉 和感应加热一样：选好 $\rightarrow$ START

---

#### 🍿 POPCORN（爆米花）

1. 按 **POPCORN**
   * 1 次：3.3 oz
   * 2 次：3.0 oz
   * 3 次：1.75 oz
2. 按 **START**

---

### 六、转盘、灯和排风

* **转盘默认开启**
  * 超大盘子可按 **TURNTABLE ON/OFF** 关闭（不推荐常用）
* **LIGHT**：打开或关闭下面炉台灯
* **VENT**：排风（高 / 低 / 关）

---

### 七、安全注意事项（很重要 ⚠️）

❌ **不要放：**
* 金属
* 铝箔
* 带金边的碗
* 密封容器（不打孔）

✅ **必须使用：**
* 微波炉安全的玻璃或塑料容器

⚠️ **不能空转**（里面没食物会损坏微波炉）
